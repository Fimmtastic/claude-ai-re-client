# Welcome to Second Brain OS

This vault is plain Markdown. The **Second Brain OS** plugin renders it as an app; everything stays readable without it.

| Folder | Contains |
|---|---|
| `00-System` | Inbox, templates, this page (not indexed as knowledge) |
| `01-Daily` | One note per day: focus, motto, habits, plan |
| `02-Worklogs/<year>` | Worklogs (Ausbildungsnachweis source) |
| `03-Knowledge/<Topic>` | Knowledge notes; `Learning/` for courses & certifications |
| `04-Projects` | One note per project — tasks inside belong to it |
| `05-Goals` | Goals from vision down to weekly actions |
| `06-Journal/<year>` | Private journal; `Reviews/` for saved reviews |
| `07-Resources` | Links, tools, references |
| `08-Archive` | Anything you want out of the way |

Templates: place `00-System/Templates/<kind>.md` (kinds: note, project, goal, worklog, journal, daily, review, learning, resource) to override the built-in templates. Variables: `{{title}}`, `{{date}}`, `{{id}}`, `{{project}}`.

Open the app: ribbon icon, or command palette → “Second Brain OS: Open Second Brain”.
